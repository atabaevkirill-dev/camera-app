# ONVIF Reticle Station

Ультрасовременная станция наблюдения для двух IP-камер в стиле SENTINEL NVR:
живой мониторинг, сплит-запись обеих камер одним файлом, прицельные сетки,
PTZ-управление, архив с превью, встроенный плеер и видеоредактор.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue) ![Qt](https://img.shields.io/badge/Qt-PySide6-green)

## Возможности

- **Мониторинг** — две камеры (ONVIF/RTSP или USB-webcam), реконнект с автовосстановлением, оверлей-прицел (Cross / Duplex / Mil-Dot) с перетаскиванием и пресетами
- **Запись** — мастер-кнопка пишет обе камеры **сплитом** в один файл; отдельная запись с каждой камеры; тумблер «Прицел: ВКЛ/ВЫКЛ» — с сеткой в кадре или чистое видео; автоконвертация в H.264 MP4
- **Архив** — галерея с превью 16:9, поиск, фильтры по камере/типу, встроенный плеер (скорость ×0.5–×4, покадровый шаг, клавиатура), удаление с подтверждением
- **Редактор** — обрезка таймлайна, скорость ×0.25–×4, разрешение 1080p/720p/480p, качество, форматы MP4/AVI/MKV, Ч/Б и контраст-фильтры, экспорт с прогрессом
- **PTZ / Зум / Фокус** — D-pad, пресеты, «домой», автофокус (скрыто за шторкой)
- **Журнал** — лента событий с уровнями; **автопоиск камер** (WS-Discovery); RU/EN интерфейс

## Быстрый старт — одна команда

**Linux / macOS**
```bash
git clone https://github.com/<you>/camera-app.git
cd camera-app
./run.sh
```

**Windows**
```bat
git clone https://github.com/<you>/camera-app.git
cd camera-app
run.bat
```

Скрипт сам создаёт виртуальное окружение, ставит зависимости (только при первом
запуске — дальше мгновенный старт) и запускает приложение. Требуется только
**Python 3.10+** (проверено на 3.14). Установить без запуска: `./install.sh` / `install.bat`.

FFmpeg отдельно ставить не нужно: конвертация в H.264 работает через встроенный
в `imageio-ffmpeg` бинарник (системный ffmpeg используется, если найден).

## Настройка камер

1. Сервис → **Автопоиск камер** (UDP 3702) — камера подставится в настройки;
2. или укажите вручную: хост/порт/логин/пароль ONVIF, RTSP URL или USB-webcam;
3. «Получить из ONVIF» подтянет RTSP-адрес потока.

Конфиг хранится в `camera_profiles.json` (создаётся автоматически, в git не
попадает — пароли). Пример структуры: `camera_profiles.example.json`.

## Запись и архив

- «● Запись обеих камер» — сплит-ролик `split_*.mp4` (обе камеры бок о бок);
- кнопка «Запись» на панели камеры — отдельный файл `cam1_*.mp4`;
- «◉ Прицел: ВКЛ/ВЫКЛ» — писать с сеткой или чистое видео;
- Архив: превью, поиск, фильтры, плеер (Space / ← / →), «Редактор» прямо из плеера;
- всё падает в H.264 MP4 автоматически.

## Структура

```
main.py              — точка входа (--selftest для smoke-проверки)
app/theme.py         — дизайн-система (SENTINEL NVR)
app/main_window.py   — оболочка: вкладки, шапка, подключение камер
app/stream_worker.py — захват RTSP/webcam, реконнект, запись
app/split_recorder.py— сплит-запись 2 камер + отрисовка прицела (cv2)
app/archive_db.py    — SQLite-архив, миниатюры, конвертация H.264
app/archive_dialog.py— галерея архива + встроенный плеер
app/editor_dialog.py — редактор (обрезка/скорость/формат/фильтры)
app/onvif_client.py  — лёгкий ONVIF-клиент (SOAP, без zeep)
app/media_convert.py — ffmpeg-конвейер H.264
app/journal.py       — журнал событий
tools/selfcheck.py   — headless-проверка UI
```

## Устранение неполадок

- **Камеры не находятся автопоиском** — проверьте firewall (UDP 3702) и VLAN;
- **Linux**: для venv нужен пакет `python3-venv`; OpenCV может требовать `libgl1`;
- **macOS**: при первом запуске разрешите доступ к камере/сети;
- логи: `logs/app.log`.

## Privacy

`camera_profiles.json`, архив, записи и скриншоты — локальные данные и
исключены из репозитория (.gitignore). Ничего не отправляется в сеть, кроме
вашего трафика к камерам.
